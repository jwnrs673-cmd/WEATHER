# 宮崎県 2026年7月 天気概況レポート

- **対象地域**: 宮崎県（宮崎地方気象台管内）
- **対象期間**: 2026年7月1日〜7月31日
- **作成日**: 2026年8月2日

> ⚠️ **本レポートは情報量が限られている。** 宮崎県固有の気象事象について、報道ベースで
> 確認できた記録が他県に比べて少なかったためである。九州南部・九州全体に共通する
> 事実を中心に構成し、**確認できなかった項目は「5. データに関する注記」に明記した。**
> 日別の観測値を含む定量的な把握には、同注記の手順で気象庁のデータを取得されたい。

---

## 1. 概要（サマリー）

2026年7月の宮崎県は、**7月13日の九州南部の梅雨明けを境に、梅雨から本格的な猛暑へと転換した** 1か月となった。

| 局面 | 期間の目安 | 特徴 |
| --- | --- | --- |
| 梅雨 | 7月1日〜12日 | 九州南部は梅雨明けせず。九州北部より5日長く梅雨が続いた |
| 梅雨明け | 7月13日 | 九州南部が梅雨明けとみられると発表。**平年より2日早い** |
| 盛夏・猛暑 | 7月13日〜31日 | 梅雨明けと同時に熱中症警戒アラート。35℃前後の日が続く |

九州北部（7月8日梅雨明け）に対し、**九州南部の梅雨明けは7月13日**で5日遅かった。この時期の宮崎県は、北部が既に猛暑局面に入っている間もまだ梅雨の中にあった。

---

## 2. 旬別の推移

### 2.1 上旬（7月1日〜10日）— 梅雨の継続

- 九州北部（山口県を含む）、中国、近畿は7月8日に梅雨明けが発表されたが、**九州南部はこの時点では梅雨明けしていない**。
- 宮崎県固有の大雨事象について、報道ベースでは具体的な記録を確認できなかった。

### 2.2 中旬（7月11日〜20日）— 梅雨明けと同時に猛暑へ

**7月12日：翌日の熱中症警戒アラートを九州全県に発表**

- 環境省と気象庁は7月12日午後5時、九州の福岡・佐賀・長崎・熊本・大分・**宮崎**・鹿児島の**7県全県**に対し、13日の熱中症警戒アラートを発表した。

**7月13日：九州南部が梅雨明け**

- 気象庁は7月13日、**九州南部が梅雨明けしたとみられる**と発表した。
  - 平年（7月15日ごろ）より**2日早い**
  - 昨年（6月27日ごろ）より**16日遅い**
- この発表に伴い、**鹿児島県の全域と宮崎県に熱中症警戒アラート**が発表された。日中の気温は**35℃前後**まで上がる所が多く、梅雨明け直後の熱中症に厳重な警戒が必要とされた。

梅雨明けの発表と熱中症警戒アラートが同日に重なった形で、**梅雨から猛暑への転換が急激**だったことを示している。

### 2.3 下旬（7月21日〜31日）— 九州全体の記録的高温

- 7月27日には大分県日田市で**40.0℃**を観測し、九州で観測史上初の酷暑日（最高気温40℃以上）となった。宮崎県も同じ高温の気団の下にあった。
- 全国の7月の平均気温は平年差**約+1.7℃**、統計史上4番目の高さとなった。
- 宮崎県固有の下旬の記録については、報道ベースでは確認できなかった。

---

## 3. この月の特徴

### 3.1 気温

- 梅雨明け（7月13日）と同時に熱中症警戒アラートが発表され、**35℃前後**の日が続く局面に入った。
- 九州北部より5日遅い梅雨明けだったため、**猛暑期間は九州北部よりやや短かった**とみられる。ただし確定値は未確認。

### 3.2 降水

- 九州南部の梅雨明けが7月13日であったことから、**月の前半は梅雨の降水がある局面**だったと考えられる。
- 宮崎県は太平洋側に面し、梅雨期は南からの湿った空気が入りやすい地形条件にある。ただし、この月の具体的な降水記録は本レポートでは確認できていない。

### 3.3 台風

- 2026年の台風7号は**6月下旬**に九州・四国方面へ接近しており、**7月の事象ではない**。
- 7月中に宮崎県へ影響した台風について、報道ベースでは確認できなかった。

---

## 4. この月の位置づけ

1. **九州南部の梅雨明けは7月13日、平年より2日早い** — 九州北部（7月8日）より5日遅く、県内は7月中旬まで梅雨の局面にあった。
2. **梅雨明けと熱中症警戒アラートが同日** — 梅雨から猛暑への転換が急激だった。
3. **九州7県全県への熱中症警戒アラート（7月12日発表・13日対象）** — 九州全体が同時に危険な暑さの局面に入った。
4. **昨年より16日遅い梅雨明け** — 前年（2025年、6月27日ごろ）と比べると、梅雨が大幅に長引いた年だった。

## 5. データに関する注記

本レポートは、公開報道および気象事業者の公表情報にもとづき、**確認できた事実のみ**で構成している。

### 確認できなかった項目

宮崎県固有の以下の事項について、報道ベースでは記録を確認できなかった。**「事象がなかった」ことを意味しない**点に注意されたい。

- 7月上旬の県内の大雨事象（記録的短時間大雨情報、警報の発表状況など）
- 県内の最高気温の記録とその地点・日付
- 7月中の台風の影響

### 気象庁データが未取得である旨

作成環境のネットワーク制限により、気象庁「過去の気象データ検索」（`data.jma.go.jp`）への直接アクセスができなかった（HTTP 403）。このため、以下の**月統計の確定値は本レポートに含めていない**。

- 宮崎（観測所）の7月の月平均気温・日最高気温の平均・日最低気温の平均とその平年差
- 月降水量合計・平年比、月間日照時間・平年比
- 月間の猛暑日・真夏日・熱帯夜の日数
- **日別の降水量・気温・湿度・風速の一覧**

これらは、本リポジトリ同梱のツールで取得できる。**本レポートの情報の薄さは、このツールを実行することで大きく補える。** 気象庁への接続が可能な環境で次を実行されたい。

```bash
python -m weather_report --pref 宮崎県 --month 2026-07
```

そのほか、以下からも確定値を参照できる。

- 気象庁 過去の気象データ検索（宮崎：`prec_no=87` / `block_no=47830`）
  `https://www.data.jma.go.jp/obd/stats/etrn/view/daily_s1.php?prec_no=87&block_no=47830&year=2026&month=7`
- 宮崎地方気象台 `https://www.jma-net.go.jp/miyazaki/`
- 宮崎日日新聞 `https://www.the-miyanichi.co.jp/`
