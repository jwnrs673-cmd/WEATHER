# 佐賀県 2026年7月 天気概況レポート

- **対象地域**: 佐賀県（佐賀地方気象台管内）
- **対象期間**: 2026年7月1日〜7月31日
- **作成日**: 2026年8月2日

---

## 1. 概要（サマリー）

2026年7月の佐賀県は、**「短く激しい梅雨末期の大雨」と「その後3週間以上続いた記録的な猛暑」** に二分される1か月となった。

| 局面 | 期間の目安 | 特徴 |
| --- | --- | --- |
| 梅雨末期 | 7月1日〜7日 | 線状降水帯による大雨。県南部を中心に土砂災害・河川増水の危険度が急上昇 |
| 梅雨明け | 7月8日 | 九州北部（山口県含む）が梅雨明けとみられると発表。**平年より11日早い** |
| 盛夏・猛暑 | 7月9日〜31日 | 太平洋高気圧に覆われ晴天と高温が持続。県内全観測点で猛暑日、月末には38.8℃ |

月の前半わずか1週間で梅雨が明け、以降は月末まで途切れることなく高温が続いた点が、この月の最大の特徴である。全国的にも7月の平均気温は平年差**約+1.7℃**、統計史上4番目の高さとなり、40℃以上の「酷暑日」が各地で相次いだ。

---

## 2. 旬別の推移

### 2.1 上旬（7月1日〜10日）— 梅雨末期の大雨から一転、猛暑へ

**7月2日未明：県南部で線状降水帯が発生**

- 気象庁は7月2日**0時30分頃**、佐賀県南部（および長崎県北部）に **顕著な大雨に関する情報（線状降水帯）** を発表。
- 同日**1時30分までの1時間雨量**
  - 嬉野市：**67.0 mm**
  - 白石町：**56.0 mm**
  - 佐賀市川副：**51.5 mm**
- **降り始め（6月30日）から7月2日5時までの累積雨量**
  - 嬉野市：**193.5 mm**
  - 伊万里市：**184.5 mm**
  - 鳥栖市：**162.0 mm**
- 佐賀地方気象台は、先行降雨で地盤が緩み河川も増水しているとして、2日夜にかけて土砂災害への警戒を継続して呼びかけた。

**7月7日：今年初の猛暑日**

- 佐賀で**35.6℃**を観測し、県内で今年初の猛暑日となった。大雨の局面から高温の局面への転換点にあたる。

**7月8日：梅雨明け**

- 気象庁は7月8日、**九州北部（山口県を含む）が梅雨明けしたとみられる**と発表。平年（7月19日ごろ）より**11日早い**梅雨明けとなった。中国・近畿地方も同日発表。

**7月9日〜10日：今季初の熱中症警戒アラート**

- 7月10日を対象に、佐賀県へ**今季初の熱中症警戒アラート**が発表された。当日の予想最高気温は**37℃**。

### 2.2 中旬（7月11日〜20日）— 西日本で記録的な高温

**7月11日：県内全観測点が猛暑日**

| 地点 | 最高気温 |
| --- | --- |
| 佐賀市 | **37.0℃**（当時の今年最高） |
| 白石 | 36.3℃ |
| 伊万里 | 36.2℃ |
| 嬉野 | 36.2℃ |

- 県内の**全観測点で35℃以上**を記録。
- この日、10代から80代までの**14人**が熱中症の疑いで救急搬送され、うち有田町の80代女性1人が畑で倒れているところを発見され重症となった。

**旬平均気温の記録的高温（西日本広域）**

7月中旬は西日本を中心に記録的な高温となり、旬平均気温の平年差は近畿+3.1℃、中国+3.5℃、四国+2.6℃と、**1946年の統計開始以来もっとも高い**値を記録した。九州北部もこの高温域に含まれ、佐賀県でも高温が持続した。

### 2.3 下旬（7月21日〜31日）— 猛暑のピーク、38℃台に到達

**7月25日・27日・28日：熱中症警戒アラートが断続的に発表**

- 7月27日の発表では、白石で**日最高暑さ指数（WBGT）34**が予測され、「著しく高温で熱中症になりやすい危険な暑さ」とされた。

**7月27日：県内今年最高の38.8℃**

- **佐賀・白石で38.8℃**を観測。県内で今年初めて38℃を超えた。
- 伊万里を除く4地点で今年の最高気温を更新。
- 一部予想では40℃到達（**県内観測史上初の「酷暑日」**）の可能性も指摘されたが、実測は38.8℃にとどまり、酷暑日の記録には至らなかった。

**7月31日：8月へ続く猛暑**

- 体温を超える暑さの予想が続き、翌週（8月上旬）には**39℃**の予想も出された。7月の猛暑はそのまま8月へ引き継がれる形となった。

## 3. 要素別のまとめ

### 3.1 気温

- 月を通じて**高温傾向が支配的**。梅雨明けの7月8日以降、月末まで途切れることなく高温が続いた。
- 県内の**7月最高気温は38.8℃（7月27日、佐賀・白石）**。
- 7月11日には**県内全観測点が猛暑日（35℃以上）**という広域的な高温となった。
- 全国平均でも7月の平均気温は平年差**約+1.7℃**で統計史上4番目の高さとなり、佐賀県の高温はこの全国的な高温傾向と整合する。

### 3.2 降水

- 降水は**7月1日〜2日の梅雨末期の大雨に極端に集中**した。線状降水帯により、わずか数時間で1時間50〜67 mmの非常に激しい雨が県南部に集中した。
- 7月8日の梅雨明け以降は太平洋高気圧に覆われ、**まとまった降水がほとんどない状態が月末まで継続**した。
- 結果として、月降水量の大半が月初の2日間で占められる、極端に偏った降り方となった。

### 3.3 防災・社会影響

- **大雨災害リスク（7月1〜2日）**: 線状降水帯により土砂災害・河川氾濫の危険度が急激に上昇。先行降雨による地盤の緩みが警戒要因となった。
- **熱中症**: 7月10日に今季初の熱中症警戒アラートが発表されて以降、7月25日・27日・28日など断続的に発表が続いた。7月11日には1日で14人が救急搬送され、うち1人が重症。
- **水資源の状況**: 佐賀県は2025年秋以降の記録的少雨により渇水対策が長期化しており、2026年4月22日時点で筑後川水系6ダムの合計貯水率は**20.8%**、佐賀東部水道企業団は10%の取水制限を継続、嘉瀬川水系でも農業用水・水道用水で5〜40%の取水制限が続いていた。7月は月初の大雨を除いて少雨だったため、水資源面では引き続き注意を要する月となった。

---

## 4. この月の位置づけ

1. **梅雨明けが平年より11日早い（7月8日）** — 高温期間が例年より2週間近く前倒しで始まった。
2. **梅雨末期の大雨が「短時間・高強度」に集中** — 総量よりも降水強度がリスク要因となった典型例。
3. **猛暑の期間が長い** — 7月中旬には西日本の旬平均気温が1946年の統計開始以来最高を記録し、下旬には県内で38.8℃に到達。40℃（観測史上初の酷暑日）が現実的な予想として語られる水準まで達した。
4. **少雨基調が継続** — 前年秋からの渇水傾向が解消されないまま盛夏に入った。

## 5. データに関する注記

本レポートは、公開報道および気象事業者の公表情報にもとづき、**確認できた事実のみ**で構成している。

作成環境のネットワーク制限により、気象庁「過去の気象データ検索」（data.jma.go.jp）および日本気象協会 tenki.jp の過去データページへの直接アクセスができなかった（すべて HTTP 403）。このため、以下の**月統計の確定値は本レポートに含めていない**。

- 佐賀（観測所）の 7月の月平均気温・日最高気温の平均・日最低気温の平均とその平年差
- 月降水量合計・平年比、月間日照時間・平年比
- 月間の猛暑日・真夏日・熱帯夜の日数

これらが必要な場合は、以下から確定値を取得のうえ本レポートに追記されたい。

- 気象庁 過去の気象データ検索（佐賀：`prec_no=85` / `block_no=47813`）
  `https://www.data.jma.go.jp/obd/stats/etrn/view/daily_s1.php?prec_no=85&block_no=47813&year=2026&month=7`
- 佐賀地方気象台 月報（`https://www.jma-net.go.jp/saga/`）

なお、本文中に記載した数値（雨量、気温、貯水率、搬送者数、発表日）は、いずれも下記出典で報じられた実測・実発表の値である。
