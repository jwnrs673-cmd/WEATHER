# 福岡県 2026年7月 天気概況レポート

- **対象地域**: 福岡県（福岡管区気象台管内）
- **対象期間**: 2026年7月1日〜7月31日
- **作成日**: 2026年8月2日

---

## 1. 概要（サマリー）

2026年7月の福岡県は、**「月初の梅雨末期の集中豪雨」と「梅雨明け後3週間続いた記録的猛暑」** に明確に二分された1か月となった。

| 局面 | 期間の目安 | 特徴 |
| --- | --- | --- |
| 梅雨末期 | 7月1日〜7日 | 筑後地方を中心に線状降水帯が発生。1時間50ミリ級の非常に激しい雨 |
| 梅雨明け | 7月8日 | 九州北部（山口県含む）が梅雨明けとみられると発表。**平年より11日早い** |
| 盛夏・猛暑 | 7月9日〜31日 | 太平洋高気圧に覆われ高温が持続。月末に県内複数地点で観測史上最高を更新 |

特筆すべきは月末である。**7月27日、久留米市と朝倉市がいずれも観測史上最高気温を更新**した。久留米は1977年の統計開始以来最も高い39.8℃に達している。

---

## 2. 旬別の推移

### 2.1 上旬（7月1日〜10日）— 筑後地方の大雨から梅雨明けへ

**7月1日〜2日：筑後地方で大雨、線状降水帯が発生**

- 福岡管区気象台は6月30日の時点で、7月1日から2日にかけて福岡県で大雨のおそれがあるとし、**筑後地方では1時間に50ミリ**の雨を予想して土砂災害や低い土地の浸水に警戒を呼びかけた。
- 7月2日**午前2時28分**、筑後地方に大雨の警報が発表された。同地方では線状降水帯が発生している。
- 同じ7月2日未明には、隣接する佐賀県南部および長崎県北部で**顕著な大雨に関する情報（線状降水帯）** が発表されており、県境をまたぐ広域的な大雨の局面だった。

**7月4日〜5日：再び線状降水帯のおそれ**

- 7月4日、西日本にのびる前線の影響で九州北部に線状降水帯が発生し、大雨災害の危険度が急激に高まる可能性があるとされた。
- 7月4日には**福岡県筑後地方で24時間120ミリ**の雨量が予想され、線状降水帯発生のおそれが伝えられた。
- 7月5日昼前から昼過ぎにかけても、福岡県・佐賀県・長崎県・熊本県で線状降水帯発生の可能性が指摘された。

**梅雨入りからの累積降水量**

- 梅雨入りが発表された**6月4日から7月7日まで**の降水量は、**福岡で582.0ミリ**（この期間の平年値342.2ミリ）。平年の約1.7倍にあたる。
- 同期間の佐賀は908.5ミリ（平年447.2ミリ）で、県境をまたいで平年の2倍以上の雨が降った地域があった。

**7月8日：梅雨明け**

- 気象庁は7月8日、**九州北部（山口県を含む）が梅雨明けしたとみられる**と発表。平年（7月19日ごろ）より**11日早く**、昨年（6月27日ごろ）より11日遅い梅雨明けとなった。中国・近畿地方も同日発表。

### 2.2 中旬（7月11日〜20日）— 西日本の記録的高温が始まる

- 梅雨明け後、太平洋高気圧に覆われて気温が急上昇した。
- 西日本では中旬から猛暑が本格化し、**福岡県の太宰府では39℃を超える**高温が観測された。

### 2.3 下旬（7月21日〜31日）— 観測史上最高を相次いで更新

**7月27日：久留米・朝倉で観測史上最高気温**

この日は九州にとって画期となる日となった。

| 地点 | 最高気温 | 記録 |
| --- | --- | --- |
| 日田（大分県） | **40.0℃**（15:30） | **九州で観測史上初の酷暑日**。1942年の統計開始以来最高 |
| **久留米（福岡県）** | **39.8℃**（16:04） | **1977年の統計開始以来、観測史上最高** |
| **朝倉（福岡県）** | **39.2℃**（13:21） | **1977年の統計開始以来、観測史上最高** |

全国では同日、15地点（うちタイ記録2地点）が日最高気温の観測史上最高を更新した。福岡県内から2地点が名を連ねたことになる。

> **注**: 7月27日の久留米の最高気温について、報道では39.3℃と39.8℃の2つの値が確認できた。上表は気象庁の観測記録更新情報にもとづく値を採った。確定値は気象庁の統計で確認されたい。

## 3. この月の特徴

### 3.1 気温

- 梅雨明け（7月8日）以降、月末まで途切れることなく高温が続いた。
- 月末には内陸部の久留米・朝倉で観測史上最高を更新。**筑後平野の内陸性の高温**が顕著に現れた月といえる。
- 全国の7月の平均気温は平年差**約+1.7℃**、統計史上4番目の高さとなった。

### 3.2 降水

- 降水は**7月上旬に極端に集中**した。梅雨入りから7月7日までの福岡の降水量582.0ミリは平年の約1.7倍にあたる。
- 一方、7月8日の梅雨明け以降はまとまった降水がほとんどない状態が月末まで続いた。
- 結果として、**月降水量の大半が上旬に偏る**降り方となった。

### 3.3 災害リスクの推移

- 上旬は線状降水帯による**土砂災害・河川氾濫リスク**が中心。特に筑後地方に集中した。
- 中旬以降は**熱中症リスク**へと局面が転換した。

---

## 4. この月の位置づけ

1. **梅雨明けが平年より11日早い（7月8日）** — 高温期間が例年より2週間近く前倒しで始まった。
2. **梅雨末期の大雨が筑後地方に集中** — 総量よりも降水強度がリスク要因となった。
3. **月末に観測史上最高気温を2地点で更新** — 久留米（1977年〜）、朝倉（1977年〜）。統計開始から半世紀近い記録が塗り替えられた。
4. **九州初の40℃到達（日田）と同日の高温** — 福岡県も同じ気団の下にあり、県内内陸部が40℃に迫った。

## 5. データに関する注記

本レポートは、公開報道および気象事業者の公表情報にもとづき、**確認できた事実のみ**で構成している。

作成環境のネットワーク制限により、気象庁「過去の気象データ検索」（`data.jma.go.jp`）への直接アクセスができなかった（HTTP 403）。このため、以下の**月統計の確定値は本レポートに含めていない**。

- 福岡（観測所）の7月の月平均気温・日最高気温の平均・日最低気温の平均とその平年差
- 月降水量合計・平年比、月間日照時間・平年比
- 月間の猛暑日・真夏日・熱帯夜の日数
- **日別の降水量・気温・湿度・風速の一覧**

これらは、本リポジトリ同梱のツールで取得できる。気象庁への接続が可能な環境で次を実行されたい。

```bash
python -m weather_report --pref 福岡県 --month 2026-07
```

そのほか、以下からも確定値を参照できる。

- 気象庁 過去の気象データ検索（福岡：`prec_no=82` / `block_no=47807`）
  `https://www.data.jma.go.jp/obd/stats/etrn/view/daily_s1.php?prec_no=82&block_no=47807&year=2026&month=7`
- 福岡管区気象台 `https://www.jma-net.go.jp/fukuoka/`
