## レポート作成の方針

- 記載する数値・日付は、出典が確認できたものだけを載せる。
- 出典は各レポート末尾に URL 付きで列挙する。
- 取得できなかったデータは省略せず、「注記」として何が欠けているかと取得先を明示する。
